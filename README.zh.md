# trustmrr-research

TrustMRR 全量普查的数据与脚本。10,150 个产品，抓取时间 2026-09-04。
文章：[一万个独立产品的收入我全抓下来了：没有快钱](https://mifanr.com/posts/trustmrr-census/)

文中的数字都能用这里的脚本重算一遍，只有一处例外：字母序分页那节里头两页的 7.0%。脱敏时产品名做了哈希，那个数依赖的页序已经没有了。算出来跟我不一样，[告诉我](https://x.com/Mifanr)。
完整说明见 [README.md](README.md)（英文），下面是要点。

## 为什么做这个

圈子里流传「TrustMRR 上 58% 的产品赚不到钱」。这个数算得没错，错在它数的是什么。

`revenue.mrr` 只统计订阅收入，一次性付费的产品这个字段恒为 0，无论卖了多少。
ShipFast 累计 127 万美元，mrr 是 0。Gumroad 近 30 天进账 714 万美元，mrr 也是 0。
数 `mrr == 0` 得到 5,930 条（58.4%），其中 1,222 条近 30 天确实在收钱。

**从没赚到过一分钱的，严格定义为三个收入字段全为零，是 2,654 条，26.1%。**

## 跑起来

不需要 API key，数据就在仓库里。

```bash
python3 report_v2.py        # 文章里所有数字，离线，几秒钟
```

想自己重新抓一份：

```bash
cp .env.example .env        # 填自己的 TRUSTMRR_API_KEY
python3 fetch.py            # 约一小时，每分钟 18 次请求，低于官方 20 次限速
python3 staleness.py        # 详情页新鲜度核验
python3 anonymize.py        # 重建脱敏数据集并自检
python3 report_v2.py
```

## 关于脱敏数据集

原始抓取结果带着每个产品的名字和创始人账号，**包括那 2,654 个从没赚到过钱的产品**。
文章的原则是没赚到钱的只做聚合、不点名，直接发原始文件会违反这条。

所以仓库里发的是脱敏版：去掉名称、slug、描述、网址、创始人账号，身份换成加盐哈希。
分析所需的字段一个不少。`founder_id` 让创始人集中度照样能算，`id` 能和新鲜度核验对上，
AI 关键词识别因为需要名称和描述，预先算成了 `ai_related` 字段。

`anonymize.py --check` 会断言脱敏文件能精确复现六个关键数字：

```
N 10150 · 从没赚过 2654 · 近 30 天在赚 4987
mrr≥5k 清洗后 353 · 去重创始人 5697 · AI 相关 5049
```

需要带名字的字段，用自己的 key 跑 `fetch.py`。

## 三个收入字段的口径

- `revenue.mrr` — 只统计**订阅**收入，一次性付费恒为 0
- `revenue.last30Days` — 过去三十天实际进账，含非订阅
- `revenue.total` — 历史累计

全站 `last30Days` 是 `mrr` 总和的 2.08 倍，剔掉 Gumroad 仍有 1.69 倍。
所以全站约四成的钱不是订阅收入，只看 MRR 会漏掉约四分之一在赚钱的产品。

## 几个改变数字的口径细节

- **头部数字全部剔除了停止同步的记录。**390 条 mrr ≥ $5,000 里 37 条已过期或超 30 天未同步，
  mrr 合计 $6,726,998，占全站 37.4%。最大一条占全站 mrr 的 19.8%，页面写着 `Stripe API key expired`，
  最后同步 2026-04-20。剔除后 353 条，占 3.5%，而不是原始的 3.8%。
- **年龄**按 `foundedDate` 折算到 2026-09-05，每月 30.44 天。1,529 条（15.1%）无有效成立日期，不计入。
- **AI 识别**用名称、描述、分类的关键词，命中 49.7%；平台分类字段是 21.2%。两种口径结论一致。
- **分页不是随机的。**API 按产品名字母序分页，前两页里 mrr ≥ $5,000 的占 7.0%，全站 2.5%。
  取前 N 页会把头部比例抬高一半，必须随机抽或者全量抓。
- **92 条 `mrr > 0` 但 `total == 0`**，字段互相矛盾，单独归为「数据不一致」。
- API 返回 10,150 条，网站首页显示 10,048 个，这 1% 的差异我没能解释。

## 这份数据不能回答什么

- **自选样本。**登记的人是愿意公开收入的人，没登记的那群人这里没有信息。
- **左截断。**平台 2025-10-31 上线，在这之前死掉的产品从来没有机会出现。
- **退出偏差。**月入五千以上约三成在挂牌，卖掉就从榜上消失。

所以 3.5%、5.1%、19.2% 都是某一天的存量比例，不是任何人的赔率。

## 已验证

脱敏数据集能精确复现原始抓取的结果。`report_v2.py` 打印的每一个数字，
无论读 `data/startups.jsonl`（原始，不发布）还是 `data/startups-anon.jsonl`（发布），
完全一致。唯一的例外是中文创始人那一小节，它需要 `name` 和 `description`，会跳过并打印说明。

## 点名

平台上的收入是产品方自己连接支付渠道后公开展示的。文章只点公开展示收入的产品与创始人，
没赚到钱的只做聚合，这也是仓库发脱敏版而不是原始数据的原因。
